# Headers, footers, page numbering and page breaks

How to add headers and footers to PDFs generated by the `HtmlToPdf` converter, number pages with placeholder tokens, control pagination with CSS, and repeat HTML table headers across pages.

## Enabling the header and footer

To make the converter render a header or footer, set `HtmlToPdfOptions.DisplayHeader` and/or `HtmlToPdfOptions.DisplayFooter` to `true` (via `converter.Options`); if these are `false` all other header/footer settings have no effect. The header and footer themselves are configured through the `converter.Header` (a `PdfHeader`) and `converter.Footer` (a `PdfFooter`) properties, whose `.Height` sets the band height in points. Both `PdfHeader` and `PdfFooter` also expose `DisplayOnFirstPage`, `DisplayOnOddPages`, `DisplayOnEvenPages`, `FirstPageNumber`, and `TotalPagesOffset`.

```csharp
HtmlToPdf converter = new HtmlToPdf();

// header settings
converter.Options.DisplayHeader = true;
converter.Header.DisplayOnFirstPage = true;
converter.Header.DisplayOnOddPages = true;
converter.Header.DisplayOnEvenPages = true;
converter.Header.Height = 50;

// footer settings
converter.Options.DisplayFooter = true;
converter.Footer.DisplayOnFirstPage = true;
converter.Footer.DisplayOnOddPages = true;
converter.Footer.DisplayOnEvenPages = true;
converter.Footer.Height = 50;
```

```vbnet
Dim converter As New HtmlToPdf()

' header settings
converter.Options.DisplayHeader = True
converter.Header.DisplayOnFirstPage = True
converter.Header.DisplayOnOddPages = True
converter.Header.DisplayOnEvenPages = True
converter.Header.Height = 50

' footer settings
converter.Options.DisplayFooter = True
converter.Footer.DisplayOnFirstPage = True
converter.Footer.DisplayOnOddPages = True
converter.Footer.DisplayOnEvenPages = True
converter.Footer.Height = 50
```

## Adding content sections

Content is placed in the header or footer with the `Add(PdfSectionElement)` method of `PdfHeader`/`PdfFooter`. Three section types can be added: `PdfTextSection` (text, like `PdfTextElement`), `PdfImageSection` (image, like `PdfImageElement`), and `PdfHtmlSection` (HTML, like `PdfHtmlElement`). For an HTML section, `PdfHtmlSection.AutoFitHeight` accepts an `HtmlToPdfPageFitMode` value (e.g. `HtmlToPdfPageFitMode.AutoFit`) so the band height adapts to its content.

```csharp
// add some html content to the header
PdfHtmlSection headerHtml = new PdfHtmlSection(headerUrl);
headerHtml.AutoFitHeight = HtmlToPdfPageFitMode.AutoFit;
converter.Header.Add(headerHtml);
```

```vbnet
' add some html content to the header
Dim headerHtml As New PdfHtmlSection(headerUrl)
headerHtml.AutoFitHeight = HtmlToPdfPageFitMode.AutoFit
converter.Header.Add(headerHtml)
```

## Page numbering

Inside the `Text` of a `PdfTextSection` (or any HTML section), the placeholders `{page_number}` and `{total_pages}` are substituted with the current page and total page count. By default page numbers start at 1 (change with the header/footer `FirstPageNumber`); `TotalPagesOffset` increments the reported total, useful when the PDF will be merged with other documents. The `PdfTextSection` constructor takes the x/y position, the text, and a `System.Drawing.Font`; `HorizontalAlign` accepts a `PdfTextHorizontalAlign` value (e.g. `PdfTextHorizontalAlign.Right`).

```csharp
// page numbers can be added using a PdfTextSection object
PdfTextSection text = new PdfTextSection(0, 10, "Page: {page_number} of {total_pages}  ",
    new System.Drawing.Font("Arial", 8));
text.HorizontalAlign = PdfTextHorizontalAlign.Right;
converter.Footer.Add(text);
```

```vbnet
' page numbers can be added using a PdfTextSection object
Dim text As New PdfTextSection(0, 10, "Page: {page_number} of {total_pages}  ", _
    New System.Drawing.Font("Arial", 8))
text.HorizontalAlign = PdfTextHorizontalAlign.Right
converter.Footer.Add(text)
```

## Rendering HTML headers/footers from a URL or HTML

`PdfHtmlSection` can be constructed from a URL (`new PdfHtmlSection(url)`) or from an HTML string with a base URL (`new PdfHtmlSection(html, baseUrl)`); set `RenderingEngine` on the section and add it to the header/footer. A different header or footer can be applied to a specific page after conversion using `PdfPage.CustomHeader` / `PdfPage.CustomFooter`, built from a `PdfTemplate` (via `doc.AddTemplate(width, height)`) holding a `PdfHtmlElement`.

```csharp
HtmlToPdf converter = new HtmlToPdf();

converter.Options.DisplayHeader = true;
converter.Header.Height = headerHeight;

PdfHtmlSection headerHtml = new PdfHtmlSection(headerUrl);
headerHtml.AutoFitHeight = HtmlToPdfPageFitMode.AutoFit;
converter.Header.Add(headerHtml);

PdfDocument doc = converter.ConvertUrl(url);

// custom header on page 3
if (doc.Pages.Count >= 3)
{
    PdfPage page = doc.Pages[2];
    PdfTemplate customHeader = doc.AddTemplate(page.PageSize.Width, headerHeight);
    PdfHtmlElement customHtml = new PdfHtmlElement(
        "<div><b>This is the custom header that will appear only on page 3!</b></div>",
        string.Empty);
    customHeader.Add(customHtml);
    page.CustomHeader = customHeader;
}

doc.Save("output.pdf");
doc.Close();
```

```vbnet
Dim converter As New HtmlToPdf()

converter.Options.DisplayHeader = True
converter.Header.Height = headerHeight

Dim headerHtml As New PdfHtmlSection(headerUrl)
headerHtml.AutoFitHeight = HtmlToPdfPageFitMode.AutoFit
converter.Header.Add(headerHtml)

Dim doc As PdfDocument = converter.ConvertUrl(url)

' custom header on page 3
If doc.Pages.Count >= 3 Then
    Dim page As PdfPage = doc.Pages(2)
    Dim customHeader As PdfTemplate = doc.AddTemplate(page.PageSize.Width, headerHeight)
    Dim customHtml As New PdfHtmlElement( _
        "<div><b>This is the custom header that will appear only on page 3!</b></div>", _
        String.Empty)
    customHeader.Add(customHtml)
    page.CustomHeader = customHeader
End If

doc.Save("output.pdf")
doc.Close()
```

## Page breaks

The converter paginates content automatically; `HtmlToPdfOptions.KeepTextsTogether` (default `True`) avoids splitting text lines across pages and `HtmlToPdfOptions.KeepImagesTogether` (default `False`) avoids splitting images. Pagination can also be forced from CSS: `page-break-before: always` inserts a break before an element, `page-break-after: always` after it, and `page-break-inside: avoid` keeps an element's content on one page where possible. These styles apply to any element (image, table, table row, div, text, etc.).

```csharp
opt.KeepTextsTogether = true;
opt.KeepImagesTogether = false;
```

```vbnet
opt.KeepTextsTogether = True
opt.KeepImagesTogether = False
```

```html
<div style="page-break-before: always">
A page break will be inserted BEFORE this div element.
</div>

<div style="page-break-after: always">
A page break will be inserted AFTER this div element.
</div>

<div style="page-break-inside: avoid">
The content of this div element will not be split into several pages (if possible).
</div>
```

## Repeat table headers

When a large HTML table spills over multiple PDF pages, the converter can repeat the table header at the top of each page. This is controlled entirely from CSS by setting `display: table-header-group` on the `<thead>` element — no API option is required.

```html
<table>
  <thead style="display: table-header-group;">
   <tr>
      <th>Month</th>
      <th>Savings</th>
   </tr>
  </thead>
  <tbody>
   <tr>
      <td>January 2009</td>
      <td>$100</td>
   </tr>
   <!--// ..... many table rows that will split over several pages ...... -->
  </tbody>
</table>
```

// No API call needed — apply the CSS above to the <thead> element of the converted HTML.
```

```
